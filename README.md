# Machine Problem #2 - ELECTIVE

### GitHub-Intro
- A simple Python program for practicing Git and GitHub workflow.

This repository is for practicing Git and GitHub basics, such as cloning, committing, pushing, pulling, and branching. It also shows a simple workflow: create a branch, make changes, open a pull request, and merge it into `main`. Collaborators work on their own branches and submit pull requests so the owner can review and merge them.
